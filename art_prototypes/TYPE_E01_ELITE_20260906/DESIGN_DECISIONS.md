# TYPE E-01 ELITE — 液态生命金属侵蚀体

## 已确认

- 用户参考图为造型验收基准；基于已确认的白色 E-01 小兵，机械机体被活体液态金属接管，不加入血肉。
- Boss 头顶高度为普通小兵的 1.5 倍；背部触须单独计算。
- 先验收 Windows PC Demo。交付范围包含可编辑 Blender、游戏用模型、骨骼、动作和游戏接入；专属技能规则与战斗平衡由现有游戏 / 总策划负责。
- 黑色金属表面流动、红脉搏动、巨爪局部伸展张合、触须运动。主体轮廓忠于参考图。
- 二阶段保留同一主体，胸核打开、红脉增强、巨爪与触须展开。
- 移动沉重并夹有失控抽动，攻击短暂停顿后骤然加速。动作资产包括巨爪横扫、下劈、突刺，以及主触须抽打与刺击。
- 在重要节点给用户先看实物再推进；避免反复无效验证。
- 所有工程、参考副本、渲染、导出、缓存及日志存储在 D 盘。

## 本轮：造型审核节点

制作独立且可编辑的整机模型，提供从实际保存文件渲染的正、背、左、右视图、三分之四视图，以及头部、核心、巨爪、背部近景。
模型的侵蚀布局、长刃轮廓、破甲厚度、材质层次为本轮重点；本轮不等同于完成动作绑定、LOD、Unity 接入或实战验收。

## 头部 R02 反馈与修订

用户反馈：“头部不够自然 而且太白了 没有残破感 不够邪恶 有点呆”。头部在独立的 `stage_02_head` 版本重建，去除等距侧鳍和完整下巴；降低眉部，缩小并加深独眼；以焦黑断缘的曲面碎甲、交织侵蚀和露出的内部结构取代完整白壳。本轮只调整头部，继续沿用整机造型审核节点。

## 造型执行默认值

- 图中三分之四主视图决定整体造型；正侧背视图用于约束体积，局部特写用于细节。图中互相矛盾的小纹路不逐条照搬。
- 人体解剖右臂异化（正面看位于画面左侧），左臂保留机械结构与拳头。
- 头部解剖左半侧侵蚀破裂，红色独眼和原机头盔轮廓仍可辨认。肩甲、胸甲、腿甲保留大块白色，侵蚀从缝隙与破口生长。
- 黑色金属以扁平流线束、交织刃片与不规则尖端构成；红色发光细脉嵌在缝隙内。避免均匀电缆、规则鳞片和整身红光遮盖几何。
- 背部建立 6 条主要可动触须及次级分叉，保留原背包与可辨认的生长根部；触须外形以本轮实际模型审核为准。
- 后续默认入场为机体失衡后重新站稳；死亡为身体倒伏、触须收缩、核心熄灭，不额外制作整机液化。

## 后续实现接口

造型通过后建立 Generic 骨骼、巨爪张合形变与触须骨骼链；分离装甲、液态主体、发光脉络和核心的材质控制。
游戏动作以原地动画为主，位移继续由游戏控制。保留胸核、右爪尖、主触须尖端的定位点，供特效与伤害系统接入。
对接现有 BossController 的动作 / 蓄力 / CoreExposed / IsPhaseTwo 状态。新的攻击动作先在动作查看场景验证，不把旧散射或炮击伤害冒充为挥爪接触伤害。
游戏接入阶段再给出单独的运行证据；Blender 预览不作为 PC 实战通过的证明。
