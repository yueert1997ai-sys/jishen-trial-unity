## 文件

- `FAZZ_CANNON_REDESIGN.blend`：可编辑 Blender 5.2 工程，零件按功能分组，保留倒角修改器；原始参考与独立设计图已打包进工程。
- `exports/FAZZ_CANNON.glb`：带材质的通用模型。
- `exports/FAZZ_CANNON.fbx`：供后续 DCC / 游戏引擎装配使用的模型。
- `reference/USER_REFERENCE.png`：用户原始参考图，建模的主要依据。
- `reference/FAZZ_CANNON_DESIGN.png`：用内置 imagegen 重绘的独立炮体设计参考，非原图无损裁切；生成图的视图可能有细节差异，模型仍以原始参考为准。
- `renders/`：实际 Blender 模型渲染，包含整体、侧面、顶部、背侧、正面炮口和中段特写。
- `EXPORT_VERIFICATION.json`：GLB、FBX 重新导入后的几何、材质、尺寸与接口检查。
- `source/`：本次建模和导出脚本。

## 使用与范围

在 Blender 中选中 `FAZZ_CANNON_ROOT` 可整体缩放或移动。当前全长约 3.5 m，是沿用旧资产量级的暂定装配尺寸，不是从原图推算出的真实尺度。炮口朝局部 -X，上方 +Z。握持、炮口、背挂和支撑接口以 `SOCKET_` 空物体标记。

背面遮挡结构、壳体厚度、圆盘安装座和局部紧固件为建模补全。圆盘使用一侧完整鼓形壳体、另一侧浅轴座的设计。此次交付是可编辑硬表面设计模型；未进行 UV 烘焙、LOD、绑定动画、机甲握持适配或 Unity 集成。

GLB / FBX 使用已应用修改器的网格，Blender 工程保留可编辑分件。导出校验包括零件数、三角面数、7 种材质、4 个接口、有限顶点坐标和包围盒尺寸。模型实际渲染与导出验证分别留存，不将生成参考图作为模型完成证据。

文件实际保存在 D 盘项目目录，当前任务 outputs 为指向该交付目录的目录联接。旧版 HC09 工程独立保留。
