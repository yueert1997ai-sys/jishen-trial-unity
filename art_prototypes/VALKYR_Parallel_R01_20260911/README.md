# VALKYR — Parallel R01

独立瓦尔基里设计线，2026-09-11。

## 文件与边界

- `VALKYR_PARALLEL_R01.blend`：新构造的完整可编辑整机，正式查看和继续迭代入口。
- `exports/VALKYR_PARALLEL_R01.glb`：独立装配交换文件，保留零件、材质与枢轴；程序化涂层微纹理以 Blender 源文件为准。
- `renders/`：从最终保存文件复开生成的整机、正面、侧面、背面、头部、腿部和背包检查图。
- `references/VALKYR_ORIGINAL_BODY.png`、`VALKYR_ORIGINAL_HEAD.png`：用户原始设计图的副本，已打包进 blend。
- `work/`：构建、分阶段细化、清理与验证脚本；未烘焙修改器的研究稿保留在 `VALKYR_R01_EDITABLE_UNBAKED.blend`。

本线没有复用 V3 的机体网格，没有替换 Unity 的 Armory.heroPrefab，没有改写当前 V3 Blender 源文件。当前 demo 只按另一项要求移除了原机体自带肩炮与支架。新版 R01 也不设肩炮。

## 设计与建模方法

外形依据原始 VALKYR TYPE-01 整机/头部图：蓝色与深蓝装甲、局部白灰面、少量金色、青色光学件；保留三角肩甲、窄腰长腿、长条前臂/胫骨甲和折叠式背包翼片。肩炮的移除覆盖原图中该附件。

FAZZ 经验用于新头部的多截面壳体、显式壁厚、前额前后体积、眼眶通道、凹入镜片与眉缘遮挡。正义经验用于承载内架、独立装甲壳、关节轴套、膝踝结构、背包进气口/喷口以及装配父级。借用的是经过实际项目检验的构造方法，没有把 FAZZ/正义部件换色后拼到瓦尔基里上。

首轮后修正头部体积、眼区宽高和头顶封闭；补充肩甲真实刻槽、前臂/腿部检修线、背包格栅和足背分件。布尔和倒角导致的小退化面进行了独立部件清理；两处异常拓扑由检查通过的对称侧重建，独立文字/编号保持不对称。

当前是 R01 首版设计研究整机，不宣称严格逐毫米复刻原图。图中遮挡的内构、后部深度和安装接口包含设计推断。胸口、脚部和机械手仍采用较简洁的造型语言，后续细化应继续以原图和本轮固定视角为对照。

## 可编辑组织

集合按装配枢轴、内架、外甲、机械件、头壳、光学件、背包和可选剑组织；可单独隐藏外甲检查内架。肩、肘、腕、髋、膝、踝和背包有装配枢轴。可选剑独立成集合并默认隐藏，交换文件不含剑的网格。

这些是装配枢轴，不是已完成蒙皮的动画骨架；尚未做动作穿插检查、游戏 LOD、材质合批和 Unity 接入。本线保持独立，适合下一轮模型审阅与细化。

## 验证

最终主机体 371 个独立网格，求值 115,366 个三角形（不含文字和默认隐藏的可选剑）。
几何检查：无无效坐标、退化面、边界边和非流形边。检查记录：`work/geometry_review.json`。
交换文件回读：`work/glb_readback.json`。最终源文件复开与渲染清单：`work/final_render_manifest.json`。

几何检查不证明没有全部部件穿插，也不代表已经达到最终造型验收或可打印实体要求。
