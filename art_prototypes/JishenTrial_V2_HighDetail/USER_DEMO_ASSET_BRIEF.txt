这是一次针对 GPT-6 + Blender 的实际建模能力测试，但最终目标不是纯展示图，而是：

【做出一台尽可能还原概念图、同时可用于我游戏 demo 的主角机 Hero Asset】

你必须兼顾两件事：

1. 尽可能还原概念设定图的造型、气质和机械细节
2. 最终产出必须能作为 demo 中可用的游戏资产，而不是只能看图的高模摆件

不要再走两个极端：
- 不要只做 low-poly / blockout 占位
- 不要只做一个无法落地的纯展示超高模

==================================================
一、最终目标
==================================================

请完成两层成果：

A. HIGH-DETAIL MASTER
用于最大化还原概念图、作为细节来源、烘焙来源、视觉基准

B. GAME-READY DEMO ASSET
用于实际进入游戏 demo，具备合理复杂度、清晰结构、基础材质与可导出能力

也就是说：

你不是只交一个“看起来差不多”的模型，
而是要完成一条从高质量造型到 demo 可用资产的完整中间流程。

==================================================
二、设计目标
==================================================

机体必须尽可能还原我给你的概念图，保留这些关键特征：

- 高机动、重装、决斗王牌机
- 宽胸、窄腰、长腿
- 中等肩甲，不坦克化
- 小腿装甲有明显重量感和结构层次
- 较小头部，双目蓝色 sensor，硬质面罩
- 右肩短炮
- 背包为高机动推进系统，默认收拢状态，但具备展开结构逻辑
- 主武器是大型 anti-ship beam blade：
  实体机械刀身 + 单侧连续蓝色光刃
- 主色深军蓝，辅以深灰 / gunmetal / off-white，发光为 electric blue
- 整体工业设计逻辑明确，避免 generic robot 和 AI 随机机械拼贴感

==================================================
三、最终交付策略
==================================================

请分两个阶段实际执行，但不要停留在粗模。

【阶段1：High-detail master】
目标：
- 尽可能还原概念图
- 重点完成 silhouette、主装甲体积、内骨架、关键机械结构
- 胸、头、腿、背包、肩炮、主武器必须明显精细化
- 允许使用较高复杂度
- 作为后续烘焙和优化来源

【阶段2：Game-ready demo asset】
基于 high-detail master，制作一个适合 demo 使用的版本：
- 结构清晰
- 面数控制合理
- 支持导出
- 具备 UV
- 具备基础材质
- 便于后续绑定和接入游戏

==================================================
四、关于“可用于 demo”的定义
==================================================

Game-ready demo asset 必须满足：

1. 不是极低模，占位感不能明显
2. 不是无限制高模，不能完全无视游戏使用
3. 结构清楚，主要轮廓和视觉重点要保留
4. 可导出为常见游戏格式（如 FBX）
5. 对象命名清楚，方便后续 rigging / integration
6. 材质槽和贴图组织清楚
7. 模型在 demo 中作为主角机近景展示不会显得廉价

如果你无法确定平台预算，请采用：

【PC / standalone demo hero asset】的保守标准

建议目标：
- LOD0 / 主展示模型：约 80k - 150k triangles（整机含背包、肩炮、武器）
- 材质数量尽量控制在 3~5 个主要材质槽以内
- 贴图分辨率优先 2K；关键区域可 4K
- 至少保留一版可烘焙/可优化的 clean asset 结构

不要为了省面数把主角机做丑。
也不要为了追求细节把它做成完全不可落地的雕像。

==================================================
五、建模优先级
==================================================

优先级如下：

1. 整体 silhouette 准确
2. 主装甲体积和比例准确
3. 工业设计逻辑成立
4. 头、胸、腿、背包、刀、肩炮的识别度到位
5. 内骨架和关节结构可信
6. 材质和发光效果
7. 三级表面细节
8. 拓扑优化与导出可用性

如果需要取舍，不要优先做微小螺丝和无意义刻线。
先保证整台机甲整体就帅，近看再有结构。

==================================================
六、High-detail master 的要求
==================================================

High-detail master 不允许停留在 primitive 拼装。

必须具备明显的 hard-surface 层级：

- INTERNAL FRAME
- PRIMARY ARMOR
- SECONDARY ARMOR
- JOINTS / BRACKETS / SUPPORT STRUCTURES
- THRUSTERS / WEAPON STRUCTURES

重点部位要求：

【头部】
- 小头比例
- 双目蓝色传感器
- 硬质面罩
- 分层头盔
- 短天线 / sensor fins
- 后脑与颈部机械结构

【胸部】
- 宽、厚、有层次
- 中央核心
- 左右胸甲
- 肩胸连接结构
- 散热 / 通风 / recessed areas
- 明显装甲厚度

【腰部 / 骨盆】
- 显著收腰
- 前裙甲、侧裙甲、后裙甲独立
- 髋部要能支撑腿部运动逻辑

【腿部】
- 大腿修长
- 小腿是重点精细区域
- 膝盖、脚踝有明确机械结构
- 小腿不能只是一个大楔形壳
- 脚不能是大鞋盒

【手臂】
- 肩关节、肘关节、腕部有机械连接
- 前臂不能只是护腕壳
- 手掌必须是真正机械手，不是几根棍子

【背包】
- 高机动推进背包
- 默认收拢状态
- 左右推进模组独立
- 有主喷口、辅助喷口、支架、连接结构
- 看起来像工业推进系统，不像装饰翅膀

【右肩炮】
- barrel
- housing
- mount
- support arm
- rotation base
- 真实连接到肩部 / 背部结构

【主武器】
- 实体机械刀身
- 厚机械刀背
- 单侧连续光刃
- beam edge 独立 mesh / 独立发光材质
- 不是普通巨剑，不是纯光剑

==================================================
七、Game-ready demo asset 的要求
==================================================

在 high-detail master 基础上，制作 demo 可用版本时：

1. 保留主要 silhouette 和装甲层级
2. 减少过细且不必要的几何
3. 对适合烘焙的细节使用 normal bake
4. 维持头、胸、腿、背包、武器的识别度
5. 优化成 clean topology，便于后续 rigging
6. 做好 UV
7. 做基础材质
8. 确保可以导出为 FBX 并供游戏项目继续使用

如果时间有限，优先完成：
- 主体机身
- 头部
- 胸部
- 腿部
- 背包
- 右肩炮
- 主武器

不要把大量时间浪费在非常次要的小配件上。

==================================================
八、材质策略
==================================================

允许制作基础材质，但不要用材质掩盖模型弱点。

材质目标：
- 主装甲：dark navy military blue
- 次级装甲：off-white / light gray
- 内骨架：dark gunmetal / black metal
- 传感器 / beam：electric blue

需要区分：
- painted armor
- bare metal frame
- dark mechanical parts
- sensor glass
- beam emission
- thruster metal

加入适量：
- roughness variation
- edge wear
- subtle scratches

不要做成废土破烂风。

==================================================
九、渲染和检查
==================================================

你必须实际自主迭代，而不是建完立刻提交。

至少执行多轮：
建模
→ 渲染
→ 自检
→ 修改
→ 再渲染

重点检查：
- 是否仍像 blockout
- 头是否过大
- 胸是否太平
- 腰是否不够收
- 腿是否不够长
- 小腿是否不够有体积
- 背包是否缺乏存在感
- 肩炮是否像临时贴上去
- 刀是否不够像 anti-ship beam blade
- 细节是否只是随机噪音而非工业设计

如果仍然明显像 primitive 拼装，不要提交。
