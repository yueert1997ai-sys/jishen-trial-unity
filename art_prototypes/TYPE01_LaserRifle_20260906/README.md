# TYPE-01 Laser Rifle

依据用户在 2026-09-06 提供的 TYPE-01 LASER RIFLE 设定图制作的独立游戏道具。该目录只包含步枪资产，没有修改主角、小兵整机或游戏场景。

## 交付

- `TYPE01_LASER_RIFLE_MASTER.blend`：可编辑主工程，原始参考图已打包。结构件、板件、紧固件、发光部件和文字分开保留，倒角修改器可编辑。
- `TYPE01_MODEL_PREVIEW.png`：白底完整实模预览。
- `TYPE01_MODEL_DETAILS.jpg`：完整实模与四组局部近景。
- `TYPE01_REFERENCE_COMPARISON.jpg`：用户原设侧面与实际模型侧面对照，等宽摆放、不拉伸模型。
- `renders/`：直接从保存的 Blender 工程生成的透明底图；`renders/white/` 为同一图像叠放于白底。
- `exports/TYPE01_LASER_RIFLE.glb`、`exports/TYPE01_LASER_RIFLE.fbx`：独立部件合并后的便携资产。

## 结构与细节

七个独立组件：机匣、镂空护木、发射筒、瞄具、可拆能量弹匣、枪托、握把与控制件。护木两侧有实际通孔，内部导管和散热片可以从孔内看到；发射筒含多层环套、凹入镜面和发光口；瞄具有镜片、安装夹具、调节环、滚花与刻度；弹匣含电量窗、锁扣、导向条和服务面板；枪托与扳机护圈均为真正镂空。握把菱形纹、螺丝、导轨齿、细小边缘磨损包含实体几何，材质另有程序化表面变化。

当前模型按参考图约 0.89 米长度建立；实测整体包围盒约为 0.893 × 0.072 × 0.266 米。用于较高的机甲时可整体等比缩放。枪口指向局部 -X，Z 向上，-Y 为主要展示侧。

挂点：`SCK_PRIMARY_GRIP`、`SCK_SUPPORT_GRIP`、`SCK_MUZZLE`、`SCK_ENERGY_CELL`、`SCK_AI_HARDPOINT`。弹匣单独父节点为 `TYPE01_REMOVABLE_ENERGY_CELL`，枪托为 `TYPE01_ADJUSTABLE_STOCK`。这些是装配辅助节点，未制作动作动画或换弹逻辑。
