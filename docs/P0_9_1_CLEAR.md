# P0.9.1 清晰画面调整

2026-09-10，针对用户“不喜欢雾面感觉，看不清楚”的反馈。

- 移除战斗相机的全屏 Bloom 扩散，F2 高粒子档也不会恢复它。
- 命中光晕直径缩至原来的约三分之一，缩短白芯闪光；刀击接触光、击杀光球和推进喷口光晕同步缩小。
