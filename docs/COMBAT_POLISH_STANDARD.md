# 战斗细节打磨标准

2026-09-18 按新批准方案更新：枪和刀都能独立成立，配合有收益。通用压力条和普通敌人强制斩杀已取消；重装敌人使用有限护甲，Boss 依靠招式后摇露核。当前实现与验证见 [Hades Rebuild V4](HADES_REBUILD_V4.md)。机制数量不作为进度或手感指标。

## 每次调整的检查顺序

1. 开火：枪口位置正确，瞬态喷焰有方向；一发子弹、一声枪响、一个弹壳，不靠持续光团模拟射击。
2. 飞行：能读出弹速和朝向；短曳光服务于运动可读性，实弹不变成光柱。碰墙和命中必须与真实弹道一致。
3. 普通命中：效果从接触处离开，局部装甲闪亮、火花和金属崩屑表达入射方向；避免全身刷白和多套通用爆点叠加。
4. 破甲：实际护甲耗尽时，动作、声音、碎甲和抗硬直变化同时发生，强度明显高于普通命中；枪刀都能继续输出，不能暗加处决门槛。
5. 刀击：刀刃扫描、切痕、火花方向、敌人反应、命中停顿和声音指向同一次接触。空挥不得产生命中反馈；残影不能遮挡敌人轮廓。
6. 击杀与继续进攻：普通命中、护甲接触、破甲、死亡、最后击杀有层次。机械零件沿受力方向脱落；停顿可被冲刺取消，残留不能挡住下一个目标。
7. 声音层次：保留枪声和刀声的节奏，给破甲和击杀留出空间；删除多余叠音，检查连续战斗混音而非只查单个文件音量。

## 每项都需经过的四种观察

- 单次：低干扰目标，确认实际接触和动作因果。
- 连续：持续射击、三连斩、多敌击杀，确认累计效果和声音不会互相遮盖。
- 正常观看：以桌面入口默认的最远 C 镜头为验收视角。近景只用于检查细节，不改变默认镜头。
- 回归：30／60／120 FPS、暂停、冲刺取消、重开、池复用、效果上限，以及基础装备、零强化的完整战斗。

每轮保存源码基线和旧构建。检查报告与原生录像通过后才更新唯一桌面入口。自动测试负责证明行为一致和没有回归；是否好玩、视觉和音色是否达到期待，由用户体验确认，不把 PASS 当成艺术质量验收。

实现集中在已有战斗反馈链和有上限的表现组件中。正式流程只接入批准的六种当局强化；不添加词条、背包切换、新地图、长期属性树或更多 Boss。
