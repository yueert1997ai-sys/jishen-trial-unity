## 调研依据与范围

该轮依据用户贴出的 AC6 调研压缩结论、原聊天中的代码评审，以及项目核心设计与实际代码。当时没有取得独立的完整版深度调研报告，不能追溯声称那时已逐页照原报告实施；后续收到的完整原文已保存在 docs/research。

核心目标是“持续施压 → 玩家制造失衡 → 抓住窗口爆发”。保留固定机体、永久武器收藏和局内强化的设计边界。这一版先落实到桌面默认的基础战斗试场，没有重做整个六场战役。

本地 R9 已经有 ImpactStability、刀刃轨迹命中、三连斩、装甲反馈和音频。本次复用这些基础，新增 Boss 联动、显式武器冲击分工和冲刺接斩；没有把原有功能冒充本次新增。

## 调研结论如何落到代码

| 调研方向 | 本次实际改动 | 主要脚本 |
|---|---|---|
| 玩家制造爆发窗口 | Boss 累积冲击后中断当前招式，露核 2.2 秒；普通出招结束不再自动露核 | ImpactStability、Damageable、BossController |
| 武器分工 | 攻击分别携带 HP 伤害、冲击值、破防追击倍率；M14 减慢射速并提高冲击 | Projectile、WeaponController |
| 枪刀衔接 | M7 与 M14 都能搭配巨剑；导弹支援可在持刀或冲刺期间使用 | PlayerLoadout、PlayerWeaponStance |
| 冲刺进入进攻 | 冲刺期间可预输入斩击；冲刺结束 0.16 秒内第一斩增加踏进 | PlayerController、PlayerMeleeController |
| 反馈有轻重 | 重击与 Break 使用不同震动；保留原有受击姿态、火花和音效 | CombatFeedback、CameraFollow |
| 高潮保持可读 | Boss 镜头最大正交尺寸从 17 收紧至 13.5；HUD 显示冲击与露核剩余时间 | CameraFollow、P0CombatDemo |

## 武器参数

以下为基础配置；装备和既有升级仍可改变实际伤害。

| 武器 | 基础 HP 伤害 | 基础间隔 | 冲击 | 破防追击倍率 | 职责 |
|---|---:|---:|---:|---:|---|
| M7 | 18 | 0.18 秒 | 30.6/发 | 1.35 | 连续命中维持压力，延迟恢复 |
| M14 | 46 | 0.65 秒 | 120/发 | 1.65 | 用低频重击迅速推进破防 |
| RAIKEN 三连斩 | 78 / 74.1 / 124.8 | 原有三段节奏 | 42 / 38 / 95 | 2.4 | 近身兑现破防窗口，沿用刀刃轨迹判定 |
| SALVO | 18/发，共四发 | 10 秒冷却 | 20/发 | 1.35 | 补充冲击，支援接近与近战 |

SALVO 目前没有新增让敌人主动闪避导弹的 AI，所以“逼位”仍未完整实现。多弹齐射分摊冲击预算，爆炸沿用命中去重，避免同一目标承受重复直击与溅射。

## Stability 与 Boss

普通敌人与 Elite 继续使用本地已有的 85 / 145 冲击阈值、1.35 秒 Break、停火 1.1 秒后每秒恢复 42 的规则。

Boss 阈值 420，Break 持续 2.2 秒；装甲状态承受 35% HP 伤害，露核时承受完整伤害。停止施压 1.5 秒后每秒恢复 60；脱离 Break 后有 0.9 秒保护，避免永久压制。基础 HP 2200，当前试场难度下实际为 1716。

造成 Break 的那一击仍按原装甲结算，之后的命中才享受窗口收益。重复命中不延长 Break，无敌和死亡状态不误触发。Break 中断 Boss 当前攻击协程，清除该招式的预警；已经射出的弹丸继续存在。恢复后延迟下一次攻击，保留原有二阶段与死亡演出。

## 冲刺与反馈

冲刺中按斩击会缓冲到冲刺结束。结束后 0.16 秒内的第一斩增加 0.55 米踏进，合计约 0.99 米，仍通过 CharacterController 处理碰撞。没有增加无敌时间，也没有凭空提高这一斩的伤害。

重击震动 0.14，Break 震动 0.30，V2 的镜头强度上限放宽至 0.40，避免原先都被压到 0.20。默认沿用 C 视野 11.25，Boss 上限 13.5。完整的镜头 A/B 玩家评估和三档动画、声音重制尚未完成。

## 试玩与验收

继续使用桌面唯一的“机神试炼”快捷方式；实际版本由 Launcher/current.json 决定。

| 操作 | 按键 |
|---|---|
| 移动 / 瞄准射击 | WASD / 鼠标与左键 |
| 斩击 / 连斩 | 右键或 Q 逐次按 |
| 冲刺 / 持续推进 | 空格点按 / 按住 |
| 导弹支援 | E |
| 切换 M7、M14 并重开 | F3 |
| 用当前枪直达 Boss | F8 |
| 同配置重开 / 暂停 | R / Esc |
| 夺取装备 | 出现提示后按 F |

默认流程是六组、共 23 个原有敌人，接现有液态 Boss，整局最多 120 秒。击败敌人所得收藏仍走原有 EquipmentLoop；这次不增加装备、Buff、地图或第二 Boss。

首版完成 14 组真实 Player 检查、1065 项 PASS，构建 0 错误、0 警告。脚本通过公开输入进行基础装备、零强化战斗：M7 73.27 秒通关、剩余 HP 78.89、Boss Break 5 次；M14 38.73 秒通关、剩余 HP 166.74、Boss Break 2 次。另有 M7 61.50 秒完整录像。不同输入策略和武器的结果不能视作严格平衡对照。

这些数据证明功能链能够完成，不证明玩家已经认可爽感。M14 通关明显更快，后续需要实玩校准。原始证据在 AuditEvidence/combat-loop-v2；中文修复版的构建与复测证据单独保存在 AuditEvidence/combat-loop-v2-textfix，旧包与旧证据保留。
