# 地图与敌人决策 R1

用户于 2026-09-23 要求重新打磨底层玩法，首先重做地图并解决 AI 显得笨的问题。本轮把第一轮可试玩改动落在路线、视线、敌人选位与进入战场的队形；地图采用功能布局原型，尚不是最终场景美术。短试场、六场正式关卡和 Boss 沿用同一套战斗规则。

## 实际改动

- 两张新布局：中继码头和反应堆。中央交战走廊、两侧连续绕行路线、不对称的六组内场掩体和外圈设备区。可走面、导航和碰撞由同一组实体生成；装饰线和盖板不增加隐形碰撞。主通道留出冲刺和刀战空间。旧月面、维修区及其资源保留，在新场景启用时关闭它们的渲染和碰撞。
- 视线按实际弹道的 1.1 米平面检测。普通远程兵被挡住时不启动射击；每隔 0.45 秒评估至多 24 个候选射位，要求完整可达路径、射线无遮挡，并考虑行程、负责的方向和队友距离。近身会先拉开，齐射后选择至少两米外的位置。
- 玩家运动采样保持独立的 0.1 秒间隔。旧代码每帧更新采样时刻，导致正常帧率下几乎永远达不到采样间隔。新代码在 30/60/120 FPS 的真实移动夹具中均读到 7.400 米/秒；预测仍受原有速度和提前量上限约束，传送不被当作速度。
- 包围方向固定在加入时分配的空闲方位。旧代码用敌人的当前方位不断旋转目标，目标会随移动继续偏转；死亡后用剩余数量分配编号也会与存活敌人重复。新分配保持方向稳定，并避开已占方位。
- 近战从各自方向逼近，接近可见目标时有短距离预判。突进必须有清晰视线和直通导航；位移使用导航移动，按实际走过的路径判断伤害，实体掩体阻挡近战伤害。落点盘和方向线均随中断清除。
- 修复近战突进结束未释放攻击名额的问题；自爆无人机也申请名额。仍保持最多三名同时攻击、最多五个存活加预留名额、短场 34 名敌人和原有快速补怪。
- 同批近战从入口前沿接近，枪兵分到左右翼。保持原有出生预警、数量、生命、伤害和奖励；精英整轮射击仍承诺预警方向，枪刀各自可以通关。

这不是行为树或状态所有权的整体替换。沿用 EnemyAttackCycle、CombatRules、EncounterFlow、StageManager、Damageable 和现有取消/暂停/死亡入口。NEMESIS、VALKYR、浮游炮、枪刀动作、特效和永久仓库沿用当前版本。

## 验证与边界

候选 `Builds/Arena_Tactics_R1`。工具 `tools/p0/run_arena_tactics_r1.py` 用隔离存档静音启动实际 Player。构建入口 `TacticalArenaBuild.Build` 重建新地图后调用现有构建器。

新 arena 套件验证：两战区各 56 条入口至侧路的完整导航；三帧率下的运动预判与突进名额释放；方位稳定和敌人替补；真实掩体前不瞎射；暂停；绕行后恢复射击；返回机库清理。掩体夹具中枪兵实际移动 6.561 米后发出三连射。

terrain 套件在新第一战区覆盖 1,468 条无阻挡路线，并检查低台阶、实体掩体、冲刺擦墙、正撞和反向脱离。另执行既有 17 组发布检查；所有最终报告须绑定最终程序集，性能与五机爆炸性能各自单独运行。

自然控制回放只使用普通 PlayerCommand，无测试补血、无敌、强制击杀或生成抑制。当前固定种子基础枪、刀、混合用时分别 50.07 / 24.53 / 31.33 秒，均击杀 34 台、名额峰值五。完整流程 249.90 秒、194 击杀、六次奖励、成功安装 E-01、零敌我脱困。它们证明流程可完成，不能解释为真人难度或好玩程度；不再恢复已被 2026-09-22 要求取代的强制 60–90 秒目标。

当前 AI 仍是局部规则决策。遮挡后保留最近已知位置，没有学习玩家策略、复杂队级任务或新 Boss 招式。地图先验证站位和路线，场景主题、细部美术及真人难度留给这轮试玩反馈。
