# 命中与掩体规则修正 · CombatContact_R1

已更新桌面「机神试炼」，继续从原入口启动。基于 CombatInteraction_R1，本轮落实 AC6 研究的第一阶段：命中反馈可信、爆炸尊重掩体、各类光束遵守一致的贴墙开火规则。

## 实际改动

- 普通弹丸的成功命中表现由已提交的伤害结果触发，删除伤害确认前额外播放的星光与红色命中闪光。无敌目标不会出现普通子弹的成功命中反馈。墙面接触和实际爆炸本身仍可有物理表现。
- 普通爆炸弹和追踪导弹现在检查爆心到目标的遮挡；隔着实墙的目标受到保护，无遮挡的同距离目标仍按原衰减受伤。
- TYPE-08、AX-01 与背炮光束共用枪口遮挡、最近碰撞、目标穿透和范围伤害规则。先检查机体到枪口之间的墙，枪口模型伸过墙也不能直接伤害墙后目标。
- 光束与普通弹丸使用同一俯视战斗平面的机体占地判定。装饰性的枪口高度不会改变命中层；模型边缘擦碰可能因规则统一而与旧版不同。
- 光束范围伤害不再只看第一条射线碰到的物体，因此中间有另一名敌人时，也不会漏掉后面的实体墙。
- 直击目标先预留，再计算溅射；多碰撞体、光束余辉不会反复扣血。范围结算快照避免死亡回调修改目标列表造成漏算或重复。
- 贴墙受阻的光束保留墙上接触表现，不从已经越墙的枪口继续画出一条虚假的有效光束。普通弹丸撞墙火花使用查询得到的墙面法线。

镜头 17、白色敌机、最新 AI、两台机体移动、刀接触停顿、基础伤害、射速与有限护甲规则沿用上一版。没有导入 AC6 资源或引擎代码。
