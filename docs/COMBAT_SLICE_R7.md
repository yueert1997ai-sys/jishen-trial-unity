# R7：枪械破甲与接刀斩杀

用户反馈：现有战斗没有明显的破防反馈，也没有破防后接刀秒杀的爽感。本轮只处理这个具体断点，默认最远 C 镜头和原固定敌群保持。

## 发现

`ImpactStability.Resolve` 已经能让 M7 三发打破普通小兵的稳定性，但没有专用破甲声音。它调用的 `MechBladeHitReaction.Trigger` 在新版 E01 身上直接返回，普通子弹的短暂受击动作随后成为唯一动作反馈。破防原先只有通用粒子和微小状态文字，第一刀没有专门的斩杀反馈。

## 修改

- `ImpactStability.cs`、`Damageable.cs`、`PlayerMeleeController.cs`：真实破防事件有独立标记。破防窗口内，真实刀刃接触直接终结普通近战／远程小兵；精英受到 2.4 倍刀伤，不走普通兵处决。子弹没有处决能力，破防那一击不算处决，窗口结束也无残留倍率。
- `E01SoldierMotion.cs`：破防瞬间的方向性反应强于普通子弹；折腰、屈膝、垂枪和重心下降持续到破防恢复，保留局部发光识别。仍由同一个敌人动作控制器更新，不再依赖已停用的旧反应。
- `OverdriveVfx.cs`：短促的两侧装甲碎光和电弧标记破防；斩杀使用不同方向和颜色的刀口碎屑。未添加扩散圆圈。
- `GameAudio.cs`、`CombatFeedback.cs`、`Audio/Combat/R7`：破甲和斩杀各有独立声音、保留播放通道；破甲那一枪不再叠普通受击声。用项目已有金属录音叠加原创瞬态、电裂和低频声体制作，不使用 Apex 素材。取消吸收不会停止这两条声音。
- `RaikenBladePresentation.cs`：斩杀首刀至少 95 毫秒刀身命中停顿，仍允许立即冲刺取消，不冻结全场。

## 验证标准

`ArmorBreakChecks` 使用生产敌人、真实 M7 子弹和真实刀刃扫描，在 30／60／120 FPS 下验证：未破防首刀不能处决；三发 M7 触发一次破甲；敌人失衡姿态、强反应和暂停冻结；子弹不会处决；第一刀终结普通兵；独立声音各一次；冲刺取消命中停顿；精英倍率、窗口过期及声音通道隔离。原生截图保存在 break 测试目录。

首次测试在取消暂停的同一帧发出单次斩击指令，该帧 deltaTime 仍为零，指令未进入模拟。保留失败报告，并在测试恢复后等待实际下一帧再输入；没有绕过刀刃命中或放宽斩杀断言。

运行 break、impact、rhythm、audio、absorption、check、regression、replay 全部实际 Player 检查。构建、报告和原生混音/录像在 `AuditEvidence/combat-slice-r7`，基线备份为 before-r7-source.zip。所有最新检查通过后才更新永久桌面入口，R6 保留。

最终记录（2026-09-16）：构建零错误、零警告；break-001345，impact/rhythm/audio/absorption-001403，check/regression/replay-001434 全部退出码 0，报告均为 `P0_CHECK code=0 errors=0`。自动输入的基础 M7＋斩舰刀整场录像 63.467 秒、46 击破、剩余 HP 141.88、胜利。原生混音峰值 0.5139，未达到削波阈值。录像仅 C 视野，不含叠加 HUD，不是呈现帧率性能测试。
