# R9：战斗音效重整

目标：基础 M7 + 斩舰刀、零强化时，听清开火、承压、破防、贯穿和机体运动。R8 保留作可玩回退。只改声音及其事件连接，不改伤害、敌人数量、移动参数或新加玩法。

## 参考与边界

- [Bandai Namco 官方 AC6 实机演示](https://www.bandainamcoent.com/news/armored-core-vi-fires-of-rubicon-gameplay-preview-video)：远近武器配合与失衡窗口是实际战斗链条的依据。
- [山村与小仓的原始开发者访谈](https://www.famitsu.com/news/202308/25314191.html)：武器手感由动作、控制、部件机构、特效与 SE 共同区分。声音必须跟着真实动作事件。
- [声音设计师 Carter Menary 的 AC6 实玩声音观察](https://www.cartermenary.com/blog/armored-core-vi-design-sound-of-rubicon)：高频短提示与中低频武器、推进区分；自身行动与危险信息优先于环境。这是作者的独立观察，并非 FromSoftware 内部实现文档。他对 side-chain 的描述也明确是推测。
- 社区提供的原声册转录中有钢厂拟音与动作可读性的说明，但未核实原始扫描文字，不据此宣称掌握 AC6 的内部参数。没有将 AC6 音频采样放进新音库。
- 本次可以做音源、频谱、包络、事件和 Unity 实际混音检查；没有真人耳听结果，不能将自动检查等同于“达到 AC6”或玩家认可。

## 已发现的问题

1. 轻刀的两个原始文件相同，重刀又使用同一材料，三个动作缺少声音区别。
2. 通用金属撞击同时承担弹着、刀击、自机受击；吸收、警报和推进也复用通用素材。
3. 普通远程敌人实际发射没有声音。落脚、收刀出刀与 F 接住缺少事件。
4. 破防虽有单独声道，只有配乐降低，持续枪声、推进与杂音仍能遮住反馈。
5. 大量声道采用循环抢占，尾音会被硬切；混音缺少动作结束、暂停和重开的一致清理。

音色顺序：步枪短爆裂与后座机构 → 细小金属承压 → 明确的断裂/能量塌落 → 刀刃贯穿与机体崩落。推进使用点火、持续负载、收油三段；冲刺有独立短喷口爆发。脚步与远处敌枪留在后景。破防、处决和自身受击暂时压低持续声，但保留动作发生的瞬间。

发布前需构建独立 R9，运行 audio、sound、gun、break、absorption、rhythm、check、regression 与实际音画回放。通过后更新同一个桌面永久入口。结果在完成时追加。

## 本轮验证中修复的问题

- 首次混音测试发现录制的模拟时钟与混音恢复使用的墙钟不同。切片声音的冷却、淡出与避让现统一使用战斗时钟；暂停时冻结，录制时跟随实际动作帧。旧 P0 模式保持原行为。
- 距离对比测试先重置上一轮受击留下的混音避让，确保在相同混音状态下比较近远声音，保留原有远距离衰减断言。
- 文件回读发现旧导入器强制使用 Vorbis，已加入 R9 的 PCM 分支，构建时重新导入并校验。修复前的录像不作为最终交付录像。
- 补上回收步枪的专用声道，敌人连射不会抢占回收后玩家的枪声。
- F 中断后立即重试会遇到旧声音冷却，现随中断清理该事务的冷却，四阶段各一次的检查已覆盖 30／60／120 FPS。

47 个新文件均为独立音源；34 类实际游戏声音事件完成原生混音逐项录制。`native-audio-analysis.json` 记录每一项输出峰值、静音结果和完整战斗混音。没有人工听感验收记录。
