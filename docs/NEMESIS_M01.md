# J-01 NEMESIS M01 — 主角动作与 demo 接入

本轮把 B20 冥隼机体作为实际玩家接入，包含原设计的步枪、光束剑、火箭炮和六枚浮游炮。用户本轮已明确授权更换 demo 主角，早先“仅外观，不修改游戏引用”的限制已被本轮要求取代。实际已发布版本始终查看 `Launcher/current.json`。

## 操作与表现

- WASD：八方向移动。空手站姿为掌心朝内、手背朝外；双脚外八。
- 左键：持枪射击。步枪采用用户两张姿态参考的单手舒展持枪：腰胸侧转、枪臂外伸、肘部轻弯、枪身略侧倾，另一只手自然配重。实际枪口与射线保持一致，近身和掩体仍参与碰撞。
- 右键 / Q：快、快、重三连斩。冥隼动作增加肩胸转动、手臂摆幅和踏步幅度，保留连续刀路、原伤害窗口、命中停顿和取消规则。
- 空格：冲刺；按住持续推进。双翼根部向外展开到约 52°，六枚翼片额外扇形张开。离开推进后收翼。
- 冲刺残影：最多四个暗紫色机体/武器姿势快照，记录实际世界位置，约 0.24 秒内淡出。使用共享低一级网格、单材质和固定对象池，无残影碰撞体；暂停冻结，死亡和返库清理。
- E：六枚浮游炮展开、发射、返航；保留支援原有总伤害预算和冷却。
- 短战斗中 Backspace 返库，在“配装”中选择光束步枪或火箭炮；两者都保留光束剑。火箭炮为双手握持并有独立重射击参数。
- 短战斗中 R 重开；Esc 暂停。原有完整流程、敌人 AI、收藏及可选战后试装仍保留。

## 实现归属

`PlayerController` 管位移与碰撞；`PlayerMeleeController` 管连击时间、命中和取消；`ValkyrMotionDriver` 执行机体姿势，冥隼通过 `NemesisComboProfile` 扩大姿态；`LoadoutVisual` 管真实握持和枪口；`NemesisMotionRig` 管腰部避让、裙甲、翼片及浮游炮；`NemesisAfterimage` 只负责残影表现。紫色刀光、枪弹、推进器不改变敌方红色弹道。

导出入口是美术工程 `work/m01_export_runtime.py`；Unity 导入/绑定入口是 `Assets/Editor/NemesisIntegration.cs`。二进制网格保留显式索引和法线，Unity 导入时统一转换三角面绕序。导入器先创建所有关节再挂父级，因此不依赖清单排序。
