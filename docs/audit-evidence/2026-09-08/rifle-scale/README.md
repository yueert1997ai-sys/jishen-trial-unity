# V9 M7 / M14 游戏比例修正

用户反馈：机库内两把枪相对机甲太小。依据正在运行的进程路径，实际修改工程是 `handoff/GameplayLoop_V1`，分支 `codex/equipment-loop-v1`（分支以现场核对为准），不是项目根目录另一套游戏。

- M7 预制件根节点等比缩放 1 → 1.65；游戏枪长实测 2.558 单位。
- M14 预制件根节点等比缩放 1 → 1.85；游戏枪长实测 2.683 单位。
- 保留网格形状与材质、主握把原点；枪口随模型等比移动。
- 两把枪的左手支撑点沿护木后移至主握把前方 0.65 单位，保留各自护木的高度。
- 机库主握点改为 (0.46, 2.22, 0.34)，持枪角度改为 (16, -68, 0)。战斗继续使用原瞄准与后坐逻辑。
- Blender 主文件及机甲几何未修改。

## 交付

可执行文件：`handoff/GameplayLoop_V1/Builds/ValkyrHangarV9_RifleScale/MECH_TRIAL_Valkyr.exe`。
项目根目录和游戏工程的 `PLAY_V9.cmd`，以及根目录 `机神试炼_V9_新机库.lnk`，均切换至上述版本。已打开的旧游戏进程不会热更新，退出后从更新的入口重新启动。
