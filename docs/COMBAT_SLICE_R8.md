# R8：实弹与刀击接触细化

针对用户对实弹、特效和挥刀对敌效果的反馈，按 `COMBAT_POLISH_STANDARD.md` 对开火至死亡的整条表现链做检查。本轮不改变枪械伤害、射速、破防门槛、连斩时序和玩家移动参数。

## 当前改动

| 环节 | 发现的问题 | R8 修改 |
| --- | --- | --- |
| 枪口 | 三个圆形光斑像通用能量光团 | 改为沿枪管的交叉锥状喷焰，减少烟雾；弹壳继承部分机体运动速度 |
| 弹体 | 出生帧未立即对齐方向；曳光拖长实体弹 | 从出生帧对齐，缩短弹体与曳光，保留 72 m/s 弹速和实体模型 |
| 接触 | 弹道／刀刃接触数据没有完整传递给表现层 | `DamageInfo` 传递接触点、法线、切割方向及命中类别；`Damageable.LastHit` 保留本次命中供死亡表现使用 |
| 普通枪击 | 多套爆点叠在一起，全身发白 | 一次接触由 `ArmorContactVfx` 处理：局部闪光、短火花、金属碎屑；减少普通子弹浮字 |
| 挥刀 | 大扇面残影覆盖目标；效果与切割方向脱节 | 收窄并缩短刀刃残影，火花按实际刀刃移动方向喷出，短暂切痕跟随装甲，敌人受力方向使用该次切割方向 |
| 破防 | 对称亮线像展开翅膀 | 换为有厚度的碎甲颗粒与少量电弧，保留失衡状态与独立破甲声 |
| 死亡 | 两层爆炸遮住动作 | 从敌人实际模型复制肩甲及背部零件脱落；使用有限碎屑和烟尘；斩杀不再叠普通死亡声音 |

新增表现组件有 48 条切痕和 24 个装甲零件槽位，火花、碎甲、烟尘粒子均有上限；开战预热，暂停冻结，返回机库和重开清理。没有增加玩法系统或修改源模型、Prefab、地图。

## 验证

- `ContactPolishChecks`：真实枪击一次一个接触、实体弹初始方向、短曳光、无额外爆炸伤害、真实刀刃扫描、切割方向传递、局部接触、装甲切痕、实际致命斩击释放原模型零件、暂停、残留过期、墙面命中和固定容量。
- `gun`：30／60／120 FPS 持续开火，一枪一弹壳、弹壳落地和过期、暂停、枪口和两手约束、弹池复用。
- `break`、`impact`、`rhythm`、`audio`、`absorption`、`check`、`regression`：保留破防首刀斩杀和之前已经验证的操作行为。
- `detail`：7 秒原生录像，前段是较远枪击后冲刺接刀，后段是三连斩。同一模拟帧分别渲染默认远景和近景；使用静止的生产敌人以便检查接触，不代替完整战斗测试。
- `replay`：基础 M7＋斩舰刀、零强化的完整自动战斗，原生画面与 Unity 混音。

证据：`AuditEvidence/combat-slice-r8`。修改前备份 `before-r8-source.zip`；构建 `Builds/CombatSlice_R8_20260916`。保留所有尝试，最终通过的最新报告和构建哈希才能发布到永久桌面入口。

近景检查发现早期版本的残影仍然过宽、普通命中全身闪亮，因此继续收窄残影并将正常闪亮限制到命中装甲；随后重录对照。后续视频只用于分析，不以拍摄镜头替换用户选择的最远 C 镜头。

最终结果（2026-09-16）：构建零错误、零警告；contact、gun、break、impact、rhythm、audio、absorption、check、regression、detail、replay 全部实际 Player 检查 PASS，进程退出码 0。近／远对照各 210 帧、7 秒，实际破防首刀击杀和完整连斩击杀均发生，混音峰值 0.5098。整场零强化自动战斗 63.300 秒、46 击破、剩余 HP 151.82、胜利，混音峰值 0.5481。录像排除叠加 HUD。

本轮验证覆盖触发、连贯性、清理和混音峰值。音色审美、连续玩下去的意愿和实际显示帧率不是这些自动测试能确认的结果。
