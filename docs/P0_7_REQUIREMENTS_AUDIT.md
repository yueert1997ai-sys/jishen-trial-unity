# P0.7：动作与需求自查（2026-09-09）

## 结论

当前是可操作、可回归的 P0 战斗原型，不能据此宣称已经达到 Hades / AC6 的体验完成度。独特性还不完整：战场抢武器尚未落地；视觉反馈与操作节奏本轮改进，主观爽感仍需要实际试玩验收。没有扩关卡、机体、Buff 或零件系统。

## 本轮发现的表现缺陷

1. 刀方向使用逐段 SmoothStep，在每个中间关键帧减速至零，身体则是连续插值。P0 改用时间感知的单调曲线，保留旧版本曲线开关默认关闭。
2. 刀光每次起手立即清空，三刀共用 0.13s 寿命。现在轻刀短、重刀长，前刀尾迹自然消散，以 stroke id 隔离网格，不把两刀连接成错误三角面。
3. 跨帧重复采样边界且所有子采样共用帧时间，产生折齿和不均匀消散。现在跳过重复边界，并记录子采样时间。
4. 重斩与轻斩使用同一套命中规模。现在区分释放时的地面压力、接触装甲后的火花/碎片；仅真实伤害触发装甲效果。
5. 75° 顶视压扁胸部与肩臂，P0 改为 68° 固定俯视；瞄准/伤害仍在水平面。
