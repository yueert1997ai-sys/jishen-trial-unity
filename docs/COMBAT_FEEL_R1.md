# 机神试炼：挥刀、受击与声音同步 R1

本轮只处理用户指出的手感重点。V4 的完整流程继续沿用；当前可玩版本以 `Launcher/current.json` 为准。真人手感、音色满意度仍未确认。

## 玩家能感觉到的变化

- **挥刀移动与转身：**起手允许修正鼠标方向，有效刀路期间锁定方向，收招重新允许转身，因此连斩可以转向新的目标。移动从起手、接触到收招分别控制，命中停顿同时冻结攻击姿势和机体移动；支撑脚在接触阶段固定于地面。冲刺取消继续有效。
- **敌人受击：**步枪的抗连续硬直时间不再挡掉紧接着的刀击。轻刀的硬直由 0.10 秒调到 0.14 秒，推移约由 0.11 米调到 0.27 米；胸腰、持枪和双臂共同偏转。完整护甲仍抗硬直，只有较小的局部震动，破甲后按无甲规则处理。
- **声音与接触：**轻刀破风在接触窗口前 20 毫秒触发，重刀提前 34 毫秒，按刀速调音高；首次真实接触时淡出破风尾音，让接触声更清楚。仅伤护甲使用金属接触音，伤到机体使用刀击音，声源放在实际接触点。破甲由已有破甲事件发声，避免重复刀击音。

## 找到的问题与相同输入的对照

修改前的 V4 并非完全没有命中音同步：实测命中事件和接触音已经在同一 Player 帧。此次不能宣称修复了原本不存在的“事件延迟”；改动针对声音层次、接触材质、破风时点，以及动作在接触时继续滑动的问题。

| 固定场景 | 修改前 | 修改后 |
| --- | --- | --- |
| 第一刀中途将手动瞄准转向右侧，接第二刀 | 第二刀仍朝原方向，约 0° | 第二刀朝新方向，90° |
| 持续向前移动并命中，统计停顿期间位移，30/60/120 FPS | 0.342 / 0.271 / 0.236 米 | 三档均为 0 米 |
| 步枪命中后约 65 毫秒接刀 | 刀击硬直被步枪免疫期挡掉 | 正常触发刀击硬直 |
| 上述刀击时敌人持枪的受击偏移 | 0 米 | 约 0.095–0.115 米 |
| 命中事件与接触音触发间隔 | 同一帧 | 同一帧 |

固定测量使用生产敌人模型与真实刀刃扫掠，1000 生命、禁用 AI 以隔离动作。它不证明实战难度或主观好玩。连续原生战斗、完整流程和近远景配对回放另行检查。

## Hades 参考边界

本地 `Content/Scripts/Combat.lua` 的护甲与硬直关系，以及 `CombatPresentation.lua` 中 `DoWeaponHitSimulationSlow` 的命中反馈组织，是设计参考。本项目的方向修正、脚底支撑、CharacterController 位移及 IK 受击为自身 C# 实现；没有把未获得的原生算法说成已还原，也没有照搬 Hades 数值。
