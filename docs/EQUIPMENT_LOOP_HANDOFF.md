# 装备夺取与随机强化 · 第一版玩法预览

2026-09-06。实现位于独立工作副本 `handoff/GameplayLoop_V1`，分支 `codex/equipment-loop-v1`，基于 `3b1f054`。未合并回主工作目录，未提交或推送。

## 启动与操作

运行本副本的 `Builds/EquipmentLoop/MECH_TRIAL_Equipment.exe`。整个同名输出目录必须一起保留。

- 机库点击“装备仓库”或按 Tab，选择已拥有的射击武器与背包；返回后出击。
- WASD 移动，鼠标瞄准，左键射击，右键 / Q 挥刀，空格冲刺，E 导弹齐射。
- 敌方装备脱落后，靠近至 10m 内按 F 或点击“吸收部件”。当前范围内的可回收部件向右手挂点飞来，立即永久入库。
- 清场时收取本区域剩余部件，避免进入选择界面后丢失战利品。选完随机强化后进入仓库，可换装，也可保持原搭配继续。
- 击败 Boss 或失败后，本局 buff 清空；已吸收的装备和所选搭配保留。重新打开游戏仍从本地仓库读取装备。

## 已实现

固定本体、永久装备仓库、敌方携带的临时模块、死亡掉落、主动吸收、清场收集、战斗间换装、随机局内强化、结算清空及重开读取。获取不会自动装备，重复获取不升级、不叠加副本；此处理是首版默认，不是最终经济系统。

| 首批装备 | 实际功能 |
| --- | --- |
| 脉冲炮（初始） | 单发，18 基础伤害，0.18s 基础间隔 |
| 裂扇散射炮（远程机兵） | 5 发扇面，每发 9 伤害，0.46s 间隔 |
| 贯穿重炮（重炮精英） | 42 伤害，0.48s 间隔，额外贯穿 3 个目标 |
| 标准推进背包（初始） | 标准冲刺，4 发导弹，技能冷却 10s |
| 矢量疾行背包（无人机） | 冲刺距离 +1.6m、冷却 -0.35s、移速 +0.6，保留 4 发导弹 |
| 蜂群火力背包（蜂群精英） | 8 发导弹，技能冷却 12s |

精英按生成次序交替携带重炮或蜂群背包。保留六场战斗至 Boss 的结构，预览中的刷怪时间点缩为原来的 30%，每批最多 3 个、同时最多 8 个。这些数量和数值均为首版可调参数。

原有强化继续随机三选一，选项随每局新种子变化。分裂强化对散射炮的每一发分别生效，换装不会删除装甲与冲刺 buff，也不会反复叠加背包属性。永久存档只写拥有的装备 ID 和当前搭配，没有 buff、等级或局内随机种子。新预览关闭旧版失败后的检查点续关，避免结算清空后恢复旧 buff。

## 与模型制作的边界

主工作目录的模型、斩舰刀、装配预制体及源文件没有被本轮编辑。独立副本沿用开工时冻结的 Jishen V3 游戏接入快照；快照清单与哈希在 `AuditEvidence/equipment-loop/source-snapshot.json`。

射击装备暂借现有肩炮发射口，并附加简单模块来区分配置。斩舰刀保持现有外观与动作，不纳入本轮换刀系统。背包也是临时附加模块，未制作最终替换模型。模块在敌人、掉落物与玩家预览间复用；完整伸手、核心重构与仪式动画后续制作。

实际查看了仓库、吸收、战斗与结算截图。检查过程中修正了装备名称与底部强化栏重叠的问题。

证据：`AuditEvidence/equipment-loop/build-result.txt`、`quick-check.txt`、`player.log` 及同目录 PNG。构建要求零错误、零警告；短流程要求零运行错误。

