# R6：F 装备吸收

以本地版本为准，沿用最远 C 视野、基础 M7 与斩舰刀、固定 46 敌战斗。此次只补齐吸收演出，不新增装备成长、背包管理或敌人类型。

## 行为与修改范围

- `SliceAbsorption.cs`：第一名指定远程 E01 使用已有步枪作为掉落物。5.5 米内且无遮挡时按 F；首次 1.05 秒、已经拥有则 0.65 秒，依次牵引、接住、锁定、启动。不使用扩散圆环。
- `EquipmentLoop.cs`、`PlayerLoadout.cs`、`E01PlayerRifle.cs`：先保存已有仓库的所有权，再开始装配；成功后同一把原武器成为手持武器，切换实际射击参数，保留斩舰刀。每局重新使用 M7，不改变永久装备选择。
- `PlayerWeaponStance.cs`、`ValkyrMotionDriver.cs`：伸手接住与收回持枪姿态，装配阶段阻止枪刀争用手部；移动照常，真实冲刺或受击取消。取消保留旧枪、掉落物和已获得的所有权，可按 F 重试。
- `E01SoldierMotion.cs`：尸体姿态不再改写已经脱离敌人的部件。
- `GameAudio.cs`：复用推进、机械锁扣、电子启动素材，取消时停止本次装配声音。
- `P0CombatDemo.cs`：清场后短暂保留最多约 3 秒拾取机会；不冻结存活敌人、不增加无敌、不改变 90 秒上限。

## 验证与发布

独立构建：`Builds/CombatSlice_R6_20260915`。修改前源码保存在 `AuditEvidence/combat-slice-r6/before-r6-source.zip`，旧 R5 构建保留。

`SliceAbsorptionChecks` 在实际 Player 的 30、60、120 FPS 下验证原武器掉落和尸体清理、距离与遮挡、写入失败、重复输入、暂停、冲刺取消、真实受击取消、四阶段完成、原模型装配、实际开火枪口、后续斩击、重开与所有权去重。各阶段原生截图随报告保存。

同时运行 rhythm、impact、audio、check、regression，以及使用 M7、零强化、不吸收的整场 replay。各次尝试包括失败记录都保留；最终结果见相应目录的 quick-check.txt 和 run.json。第一次吸收测试禁用了敌人组件，导致其死亡订阅失效；修正测试为生产中的启用状态后重跑，而非绕过死亡掉落流程。

发布必须由 `publish_playable.py` 核验构建文件哈希和全部相关模式的最新 PASS，才能更新永久桌面入口。自动测试不代表人工认可“爽感”；吸收演出在最远镜头下的可读性、音色和重复游玩意愿仍需用户体验。

最终结果（2026-09-15）：构建零错误、零警告。absorption-233738、rhythm-233751、impact/audio/regression/check-233812、replay-233822 均为 `P0_CHECK code=0 errors=0`，实际进程退出码 0；完整时间戳在证据目录中。零强化、不吸收的原生战斗录像为 65.133 秒、46 击破、剩余 HP 145.19，胜利；混音峰值 0.4940。录像只捕获 C 视野，不包含叠加 HUD；这不是人工试玩或呈现帧率性能测试。

下一轮回到整场打磨：优先处理试玩暴露的节奏断点、威胁可读性和操作响应，不扩系统。
