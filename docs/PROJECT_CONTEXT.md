# 项目上下文总结

## 项目目标

制作一个 Unity 6 的原创机甲题材、上帝视角、肉鸽射击 Demo。当前目标是尽快得到一个真正能玩的短流程版本。

核心体验：

- WASD 移动；
- 鼠标瞄准和射击；
- 波次战斗；
- 战后获得强化；
- 进入下一关；
- 击败 Boss；
- 查看胜负结算并重新开始。

## 当前主角机

已提供：

`Assets/UserContent/PlayerMech/Meshy_AI_Rose_Gold_Sentinel_0618172915_texture.glb`

它暂时作为客串主角机使用。

已知信息：

- 文件约 38 MB；
- 接近 94 万三角面；
- 基本是单一主 Mesh；
- 带 PBR 材质和贴图；
- 暂不适合做模块化装备；
- 第一版 PC Demo 允许先直接使用；
- 只有出现明显性能问题时再降面。

## 当前暂停内容

- 不再反复用 Meshy 生成主角机；
- 不继续尝试四视图直接生成高质量 3D；
- 暂停装备外观模块化；
- 暂停换枪、换盾、肩部导弹舱等复杂装配；
- 暂停复杂骨骼动画；
- 暂停存档、多人、长剧情和复杂局外成长。

强化第一版只改变数值、弹道、特效和技能表现。

## Demo 流程

1. 机库或简单开始区域；
2. 开始任务；
3. 第一关：3 波普通敌人；
4. 战后出现三选一强化；
5. 第二关：更多敌人和一名精英；
6. Boss 战；
7. 胜利或失败结算；
8. 重新开始。

## 玩家能力

- WASD 移动；
- 鼠标瞄准；
- 左键射击；
- 空格冲刺；
- HP、受伤、死亡；
- 相机 45 度斜俯视跟随。

## 强化示例

- 伤害提升；
- 射速提升；
- 多发子弹；
- 子弹穿透；
- 子弹爆炸；
- 最大生命提升；
- 冲刺冷却降低；
- 击杀回复少量生命。

## 敌人

- 近战追击敌人；
- 远程射击敌人；
- 自爆或高速无人机；
- 精英敌人；
- 重装 Boss。

## 模型接入要求

建议结构：

```text
PlayerMechRoot
├── VisualRoot
│   └── RoseGoldSentinel
├── Collider
├── WeaponMuzzle
├── CameraTarget
└── GroundCheck
```

要求：

- 高度调整到约 2.8 米；
- 脚底贴地；
- 正面朝 +Z；
- 玩法脚本挂在 `PlayerMechRoot`；
- 视觉模型只负责显示；
- 若 Unity 不能直接导入 GLB，优先使用 `glTFast`；
- 保留原始 GLB；
- 保存为 `PlayerMech_Guest.prefab`。

## 执行原则

- 优先能运行；
- 每完成一个模块都进入 Play Mode 验证；
- 读取 Console 并修复阻断性错误；
- 不要一次创建大量未经测试的脚本；
- 不使用真实高达 IP 名称或素材；
- 不读取项目目录外的私人文件；
- 不使用 `git add .`；
- 修改前后执行 `git status`；
- 重要决策和已知问题写入 `docs/HANDOFF.md`。

## 当前最重要的验收目标

- 打开场景后看到当前 GLB 主角机；
- 机甲可移动、瞄准、射击和冲刺；
- 能打完第一关；
- 能选择一次强化；
- 能进入第二关；
- 能打 Boss；
- 能看到结算；
- 整个流程没有阻断性报错。
